# Supabase project structure (placeholder)

This directory is reserved for the Supabase project configuration that will
be added in a later implementation step:

- `migrations/` — versioned SQL migrations for the application schema
  (products, product_releases, collection_items, price_points, etc. — see
  the TrackDash backend architecture document for the full design).
- `config.toml` — Supabase CLI project config (generated by `supabase init`),
  to be added once local Supabase CLI development is set up.

**Step 1 status**: no database schema exists yet. This directory only marks
where it will live. Auth is not implemented either — see `lib/supabase/`
for the client/server/middleware plumbing prepared so far.
