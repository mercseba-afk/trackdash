# Vintage catalog evidence conflicts

Research log for official-source discrepancies encountered during the Vintage 100 pilot. A conflict here does not automatically mutate the production catalog; the strongest release-specific evidence wins only after the contradiction is documented.

## 18023 — Dash-5 Dancing Doll — chassis

**Production catalog value retained: `Type 3`.**

### Evidence supporting Type 3

1. Tamiya's dedicated product page for ITEM 18023 explicitly states `タイプ3シャーシ` in the product description and lists the machine under the Type 3 chassis section. It also states initial release month March 1990.
   - https://www.tamiya.com/japan/products/18023/index.html
2. Tamiya's dedicated Type 3 chassis index independently lists ITEM 18023 Dash-5 Dancing Doll among Type 3 machines.
   - https://tamiya.com/japan/products/product_info_ex.html?genre_item=mini4wd_chassis_type3%2Cmachine_kit

### Conflicting evidence

A historical/retrospective Tamiya Jr. News PDF (`000191.pdf`) contains a summary grid/text that labels ITEM 18023 as `タイプ1シャーシ`.
- https://www.tamiya.com/cms/japan/mini4wd/jr_news/jr_news16/pdf/000191.pdf

### Decision

Keep `Type 3`. The dedicated ITEM page and the dedicated chassis taxonomy independently agree on Type 3 and are more release-specific than the retrospective summary. The Jr. News conflict remains documented rather than silently discarded. If a future archival source demonstrates a distinct Type-1 commercial occurrence for ITEM 18023, that occurrence must be modelled as a separate Release rather than overwriting the 1990 Type-3 Release.
