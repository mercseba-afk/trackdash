# R3 data boundary

R3 distinguishes architecture go-live from provider/data activation. Shipping the R3 code and storage does not imply that a provider scanner is active or that every Release already has a current market signal.

Public behavior is fail-closed: no current purchasable observation means no `A partire da`; no real R3 signal means no synthetic market valuation. Historical/out-of-stock prices remain evidence only and never become a current purchasable price.
